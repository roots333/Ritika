## GitHub Pages
Upload `index.html` and the entire `assets` folder to a repository.
Then: Settings → Pages → Deploy from branch → `main` → `/root`.

## Music
A music control is built into the site. Add your licensed/royalty-free Rajasthani instrumental as:
`assets/rajasthani-ambient.mp3`
